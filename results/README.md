# results/

Salidas generadas por el pipeline: figuras, tablas y artefactos intermedios.

- Las figuras (`.png`, `.pdf`) y tablas ligeras (`.csv`) se versionan.
- Los `.mat` pesados se ignoran en git (ver `.gitignore`).
- Convención de nombres: `<fase>_<rodamiento>_<descripcion>.png` (p. ej. `eda_bearing1_1_rms_trend.png`).
